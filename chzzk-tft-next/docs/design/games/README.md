# 게임 카드 이미지

`/home` "지원 게임" 섹션의 카드 상단 이미지 원본을 둔다.

| 파일 | 게임 |
|---|---|
| tft.png | Teamfight Tactics |
| lol.png | League of Legends |
| valorant.png | VALORANT |
| overwatch2.png | Overwatch 2 |
| maplestory.png | MapleStory |

- 이 폴더(`docs/design/games/`)는 디자인 원본·관리용이다. PNG는 `.gitignore`(`/docs/design/**/*.png`)로 Git에 올라가지 않는다.
- 웹페이지에서 실제로 쓰는 파일은 같은 이름으로 `public/games/`에 둔다 (예: `/games/tft.png`).
- 게임 이미지·아트워크는 각 게임사의 저작물이다. 배포 전에 사용 권한(팬 사이트 정책·보도자료 이용 조건 등)을 확인한다.
